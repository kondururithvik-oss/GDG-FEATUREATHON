## Repository Descriptions

### 1. Photo & Video Management — [immich-app/immich](https://github.com/immich-app/immich)
A high-performance, self-hosted photo and video backup platform built as a direct replacement for Google Photos. It features native iOS and Android background sync, hardware-accelerated video transcoding, shared albums, EXIF map views, and machine-learning-powered facial recognition and semantic search.

### 2. Collaborative Workspace & Notes — [AppFlowy-IO/AppFlowy](https://github.com/AppFlowy-IO/AppFlowy)
A privacy-first, local-first workspace that combines rich-text documents, relational databases, Kanban boards, and calendars as an open-source Notion alternative. Built with Rust and Flutter, it delivers fast native desktop and mobile performance while allowing teams to self-host their cloud sync backend.

### 3. Password & Vault Management — [dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden)
A lightweight, Rust-based server implementation compatible with official Bitwarden desktop, mobile, and browser clients. It provides end-to-end encrypted personal vaults, organization password sharing, two-factor authentication (TOTP/FIDO2), and secure file attachments with minimal server memory footprint.

### 4. On-Demand OTT Media Streaming — [jellyfin/jellyfin](https://github.com/jellyfin/jellyfin)
A free-software media server that organizes personal collections of movies, TV shows, music, and live TV and streams them to web, mobile, and smart-TV apps. It delivers a Netflix-like streaming experience with multi-user profiles, watch-progress syncing, automated metadata scraping, and hardware-accelerated FFmpeg transcoding.

### 5. Social Microblogging Network — [mastodon/mastodon](https://github.com/mastodon/mastodon)
A decentralized, federated microblogging platform powered by the ActivityPub protocol as an open-source alternative to X (Twitter). Anyone can run an independent server ("instance") with custom moderation policies while allowing users to follow, reply to, and boost posts seamlessly across the global Fediverse.

### 6. Scheduling & Calendar Booking — [calcom/cal.com](https://github.com/calcom/cal.com)
An open-source scheduling infrastructure and Calendly alternative that eliminates back-and-forth emails when booking meetings. It supports multi-calendar availability syncing (Google, Outlook, CalDAV), round-robin team routing, custom booking workflows, payment integrations, and embeddable widgets.

### 7. Team Chat & Real-Time Messaging — [RocketChat/Rocket.Chat](https://github.com/RocketChat/Rocket.Chat)
A self-hosted team communication platform built as an open-source alternative to Slack and Discord. It includes public and private channels, threaded discussions, direct messaging, file sharing, omnichannel customer support integrations, and end-to-end encryption for security-sensitive organizations.

### 8. Cloud Storage & File Sync — [nextcloud/server](https://github.com/nextcloud/server)
A comprehensive self-hosted cloud content collaboration platform serving as a replacement for Google Drive and Google Workspace. Beyond cross-device file synchronization and granular link sharing, its app ecosystem extends into collaborative document editing, calendars, contacts, tasks, and encrypted video calls.

### 9. Video Conferencing & Meetings — [jitsi/jitsi-meet](https://github.com/jitsi/jitsi-meet)
A secure, scalable WebRTC video conferencing platform that works directly in web browsers without requiring client software installs. Comparable to Zoom and Google Meet, it offers HD audio/video, screen sharing, breakout rooms, live streaming, end-to-end encryption, and embeddable SDKs.

### 10. Video Hosting & Live Streaming — [Chocobozzz/PeerTube](https://github.com/Chocobozzz/PeerTube)
A decentralized, ActivityPub-federated video hosting and live-streaming platform designed as an ad-free alternative to YouTube. It supports creator channels, subscriptions, playlists, FFmpeg adaptive transcoding, and peer-to-peer WebTorrent streaming so viewers help distribute bandwidth during popular broadcasts.
